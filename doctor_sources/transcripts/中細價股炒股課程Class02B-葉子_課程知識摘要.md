## 核心觀念

### 1. 買殼的本質是上市公司控制權由舊主轉到新主

老師把「買殼」簡化為：

**原主控制上市公司 → 把控制權出售 → 新主取得上市公司的控制權。**

重點不是單純買一批股票，而是上市公司的控制權發生轉移。

新主取得上市地位後，可以再把自己的私人公司、資產或業務注入上市公司。

### 2. 買殼本身不等於傷害市場

老師特別提醒，不要把「買殼」這個行為本身妖魔化。

課堂提到，不同類型企業都可能透過買殼形式取得上市地位。老師的重點是：

**買殼是一種工具；真正要分析的是背後的人如何使用這個工具。**

因此不能建立「買殼 = 一定有問題」的固定判斷。

### 3. 選擇買殼而不是 IPO，主要是為了取得上市地位

老師提出兩大方向。

第一類是**不想走正常 IPO 的時間及程序**：

-   IPO 要等待；
-   需要符合一系列上市要求；
-   需要已有實際營運及業務；
-   整個上市過程涉及時間及成本。

若新主不想等待，可以直接買入已有上市地位的公司，再注入自己的資產或業務。

第二類是**本身暫時難以直接 IPO／不希望經歷完整 IPO 審查**。

逐字稿提到：

-   帳目／數字可能敏感；
-   新概念或新公司可能尚未具備正常上市條件；
-   有些人有資金、有概念，但缺乏可立即上市的公司；
-   因此可能先取得一個上市平台，再利用上市公司集資及發展業務。

老師亦提到部分「枱底」原因，但沒有建立可直接套用的固定判斷規則。

### 4. 買殼主要分 GO 與 Non-GO

本課先建立兩個分類：

1.  **GO**
2.  **Non-GO**

GO 全名為 **General Offer**，課堂譯作「全面收購」。

本課主要講 GO；老師表示 Non-GO 較複雜，留待後續課堂。

### 5. GO 的核心是：要約人向股東提出一個要約價

GO 的基本形式是：

-   新主／要約人提出收購；
-   設定一個「要約價」；
-   股東可在指定期限內決定是否把股份按要約價出售給要約人。

因此 GO 分析的核心詞包括：

-   要約人；
-   要約價；
-   要約期限；
-   是否附帶條件；
-   最終收購到多少股份。

### 6. GO 的制度作用之一，是在控制權改變時給公眾股東退出選擇

老師用「投資股票其實不只是買一張股票」去解釋 GO 的意義。

投資者買入一家公司，實際上可能是在買：

-   公司業務；
-   公司資產；
-   公司背後的人及管理能力。

若原本投資者相信舊主，但舊主突然把控制權賣給另一個完全不同的新主，公眾股東原本所依賴的「人」已經改變。

因此 GO 的作用之一，是在控制權轉移時讓公眾股東有機會按某個要約價退出。

### 7. 強制性 GO 有特定觸發條件

老師在課堂列出兩個主要條件：

#### 條件 A：持股由 30% 以下升至 30% 或以上

如果某一方原本持股低於 30%，其後一次交易令持股達到／超過
30%，會觸發老師所講的強制性全面收購。

#### 條件 B：本身持有 30%--50%，12 個月內再增持超過 2%

老師例子：

-   原持股 32%；
-   一年內增至 33.9%，仍未到 2%；
-   若增至 34%，即增加 2%，便觸發強制性 GO。

本摘要只保留老師在本課所講的判斷框架，不自行補充其他監管細節。

### 8. 自願性 GO 不需要先觸發強制條件

自願性 GO（Voluntary GO／VGO）是要約人主動提出收購。

老師的區分是：

-   強制性：因達到某些條件而必須提出；
-   自願性：沒有被規則強制，也可以主動提出。

### 9. GO 還要再分「有條件」與「無條件」

老師把 GO 再拆成：

-   有條件；
-   無條件。

自願性有條件 GO 的典型結構是：

**要約人本身持股 + 一致行動人士持股 + 接納要約所得股份**

需要達到某個指定比例，例如老師課堂以超過 50% 作說明，GO 才繼續完成。

如果最後未達條件，該次 GO 可以失效／取消。

### 10. 自願性無條件 GO 較少見，老師認為值得特別留意

老師指出，自願性 GO
本身已經不是被迫提出；若連完成條件也不設，代表要約人願意直接承擔收購。

老師把這種情況視為可留意的訊號，認為可能反映要約人對收購具有較強意願或信心。

但本課沒有把「自願性無條件 GO」定義成必升訊號。

### 11. GO 不一定全部以現金支付

老師提醒，GO 的代價不一定完全使用現金。

可能出現：

-   現金；
-   其他公司的股份；
-   混合支付方式。

本課沒有深入展開複雜支付結構。

### 12. GO 的一個優點是「乾手淨腳」

老師把 GO 形容為較「乾手淨腳」的買殼／控制權轉移方法。

原因包括：

-   有清楚的要約價；
-   公眾股東自行決定是否接受；
-   整個收購按既定程序進行；
-   新舊控制權交收較清晰。

### 13. GO 亦可以協助舊主的「暗手」一併交收

老師指出，舊主實際控制或相關的貨源未必全部放在舊主本人名下，可能另有俗稱「暗手」的持股。

當新主提出 GO 時，相關持有人亦可以按要約價把股份交給新主。

因此 GO 不只是處理名義大股東的控制權，也可能成為相關貨源一併交收的渠道。

### 14. 研究殼不能只看「有沒有殼」，要看殼的質素

課堂後段開始建立「殼質素」概念。

老師不希望新主買入一間負擔過重、問題大到難以處理的上市公司。

理想情況不是公司一定非常優秀，而是：

**即使公司基本面一般或有虧損，也不能爛到新主難以清理。**

老師以「虧幾百萬」與「虧幾百億」作極端比較，說明兩者對新主承接後的負擔完全不同。

### 15. 「爛」不等於不能做殼，關鍵是問題是否容易處理

老師的意思不是只找盈利公司。

一家公司可以：

-   有虧損；
-   業務一般；
-   質素不算好；

但如果問題仍在可處理範圍，仍可能符合老師所講的殼條件。

真正不理想的是：

-   巨額持續虧損；
-   大量債務；
-   新主接手後需要承擔非常沉重的財務問題。

### 16. NAV、現金及負債是研究殼價值的重要元素

老師把 NAV 解釋為：

**資產 − 負債 = 股東權益／NAV。**

但老師同時提醒，不能把帳面 NAV
全部當成真正可實現價值，因為資產可能存在「發水」情況。

因此分析殼時，要進一步區分：

-   帳面資產；
-   負債；
-   現金；
-   資產實際質素。

老師把現金視為較直接、較難「發水」的部分，因此在估算殼的價值範圍時特別重視。

## 判斷條件與邏輯

### 一、先確認是否屬控制權轉移／買殼事件

檢查：

-   原主是否出售大比例股權；
-   新主是否取得控制權；
-   是否伴隨 GO；
-   新主是否準備把新資產或業務注入上市公司。

### 二、判斷新主為甚麼選擇買殼

按老師框架思考：

1.  是否希望節省 IPO 時間？
2.  是否已有資金或概念，但公司暫未符合正常上市條件？
3.  是否希望取得上市平台後再集資發展？
4.  是否存在其他不能單靠公開資料直接確定的原因？

不能看到買殼便自行假設單一目的。

### 三、確認 GO 類型

先分：

-   強制性；
-   自願性。

再分：

-   有條件；
-   無條件。

形成四個組合去理解事件。

### 四、強制性 GO 檢查持股門檻

按課堂框架檢查：

-   是否由 30% 以下升至 30% 或以上；
-   或本身持有 30%--50%，12 個月內是否再增持約 2% 或以上。

### 五、如屬有條件 GO，要找清楚完成條件

不能只看到「提出 GO」便當作一定完成。

要看：

-   要約人現有持股；
-   一致行動人士持股；
-   接納股份；
-   最低完成條件；
-   最後是否達標。

### 六、研究要約價

要約價是 GO 的核心數字之一。

需要理解：

-   股東可以用甚麼價格退出；
-   新主願意用甚麼價格收貨；
-   要約價與市場價格的關係。

本課沒有建立「低於／高於要約價多少便買入」的固定交易公式。

### 七、研究 GO 是否能完成新舊貨源交收

除了名義控制權，亦要思考：

-   舊主是否有相關暗手；
-   GO 是否讓相關股份一併交給新主；
-   新主最終可取得多少貨源。

### 八、研究殼質素

至少看：

1.  公司虧損程度；
2.  負債；
3.  現金；
4.  NAV；
5.  資產質素；
6.  是否存在大量「發水」資產；
7.  新主接手後是否容易處理舊公司的財務問題。

### 九、不要只看帳面 NAV

老師明確提醒：

**NAV 是資產減負債，但資產本身可能不值帳面所寫的價值。**

因此不能機械地把 NAV 當成殼的真實價值。

## 老師重點

-   買殼的本質是控制權轉移。
-   買殼本身不是壞事，關鍵是背後的人如何使用上市平台。
-   新主選擇買殼的重要原因之一，是不想等待正常 IPO。
-   有概念、有資金但暫未有合資格上市公司的項目，也可能透過買殼取得上市地位。
-   買殼主要可分 GO 與 Non-GO；本課重點是 GO。
-   GO 即 General Offer／全面收購。
-   要約價是 GO 必須掌握的核心概念。
-   強制性 GO 與自願性 GO 的成因不同。
-   GO 還要分有條件及無條件。
-   有條件 GO 未達條件可以失效，不能看到公告便當作收購一定完成。
-   自願性無條件 GO 較少見，老師認為值得留意。
-   GO 不一定全部以現金支付。
-   GO 的好處之一是控制權及貨源交收較清晰。
-   GO 可能同時處理舊主相關暗手的貨源。
-   研究買殼不能忽略上市公司本身的財務包袱。
-   老師偏好問題仍可處理的殼，而不是負債、虧損嚴重到難以清理的公司。
-   NAV 只是起點，資產可能發水。
-   現金、負債及資產質素需要分開看。

## 操作流程

### Step 1：找出控制權變動

確認：

**舊主 → 新主**

之間是否發生大比例股權出售。

### Step 2：確認是否出現 GO

查看是否由新主／要約人提出全面收購。

### Step 3：分類 GO

標記：

-   強制／自願；
-   有條件／無條件。

### Step 4：如屬強制性 GO，檢查觸發原因

按老師本課框架檢查：

-   30% 門檻；
-   30%--50% 區間內 12 個月增持約 2% 的情況。

### Step 5：記錄要約價及期限

要知道公眾股東：

-   可以用甚麼價出售；
-   在甚麼期限內決定。

### Step 6：如屬有條件 GO，記錄完成條件

例如：

**要約人 + 一致行動人士 + 接納股份 \> 指定比例。**

等待最終結果，不把「提出」等同「完成」。

### Step 7：分析新舊貨源交收

除了大股東名義股份，亦留意相關持股是否可能透過 GO 一併交收。

### Step 8：分析新主買殼目的

研究其可能是：

-   取得上市地位；
-   注入私人資產／業務；
-   利用上市公司進一步集資；
-   進行真正業務發展。

若資料不足，不強行推斷。

### Step 9：檢查殼的財務質素

查看：

-   盈虧；
-   負債；
-   現金；
-   NAV；
-   資產組成。

### Step 10：判斷舊公司的問題是否「可清理」

老師的重點不是公司一定要盈利，而是：

**新主接手後，舊問題是否容易處理。**

## 重要案例

### 案例一：以知名企業／企業家說明買殼並非必然負面

老師列舉多個曾以類似買殼方式取得上市平台的企業案例，並以汽車公司等作說明。

由於逐字稿部分公司名稱及代號存在辨識錯誤，本摘要不自行校正全部名稱。

案例目的只有一個：

**不能因為公司是買殼上市，就直接判定為負面。**

### 案例二：Mark Zuckerberg 假設例子

老師假設一名已被市場認可的企業家突然成立一家全新的私人公司。

即使市場相信他的能力，新公司也未必能立即符合正常 IPO 條件。

其中一個可能做法是：

**先買入上市殼 → 再把私人公司／業務注入 → 利用上市平台發展及集資。**

案例用來說明「有概念、有能力，但缺乏即時上市資格」的買殼動機。

### 案例三：32% 增至 34%

老師以強制性 GO 解釋：

-   原本持有 32%；
-   一年內升至 33.9%，尚未增加 2%；
-   若升至 34%，達到老師所講的增持門檻；
-   因而需要提出強制性全面收購。

案例用途是建立對「持股區間 + 增持速度」的敏感度。

### 案例四：自願性有條件 GO

要約人主動提出收購，但設定最低持股條件。

若：

**自身持股 + 一致行動人士 + 接納股份**

最終未達指定比例，GO 可以取消。

案例重點：

**提出 GO ≠ GO 一定完成。**

### 案例五：GO 協助暗手交收

假設舊主除名義持股外，另有相關人士／暗手持貨。

新主提出 GO 後，這批相關股份亦可按要約價交給新主。

老師用此說明 GO
的「乾手淨腳」：除了名義控制權，也可能一併完成相關貨源交接。

### 案例六：「虧幾百萬」與「虧幾百億」

老師以極端數字比較殼的質素。

若上市公司只是有限度虧損，新主可能較容易處理；若存在極端巨額虧損或負擔，新主買入後也要承受這些問題。

案例重點：

**殼不是愈爛愈好，而是問題要在可處理範圍。**

### 案例七：NAV 與發水資產

老師指出：

**NAV = 資產 − 負債。**

但若帳面資產本身被高估，NAV 亦會失真。

因此研究殼不能只抄一個 NAV 數字，而要看：

-   資產是否真實有價值；
-   現金有多少；
-   負債有多少。

## 例外與容易誤判情況

### 1. 買殼不等於一定是財技騙局

老師明確反對把買殼本身妖魔化。

### 2. 買殼亦不等於一定有真正業務發展

同一工具可被不同人用作不同目的。

### 3. GO 公告出現不等於收購已完成

有條件 GO 必須等待條件達成。

### 4. 強制性 GO 不代表新主一定特別看好公司

它可能只是因為持股變化觸發規則。

### 5. 自願性 GO 與強制性 GO 不可混為一談

兩者背後的原因不同。

### 6. 自願性無條件 GO 值得留意，但不是必升條件

老師只是認為其可能反映較強收購意願。

### 7. 要約價不是股票必然價值

它是要約人提出的收購價格，不能直接等同公司真正價值或未來股價。

### 8. NAV 不等於可實現價值

帳面資產可能發水。

### 9. 公司有虧損不代表不是好殼

重點是虧損及負擔是否在新主可處理範圍。

### 10. 公司「很爛」亦不代表更有殼價值

如果債務或虧損過重，反而增加新主接手成本。

### 11. 逐字稿中部分「殼／買殼」被辨識為「學、賀、鶴」等

這些只在上下文高度確定時修正；其他不確定專有詞不自行補全。

3.  GO 必須同時看「類型、條件、要約價、期限、最終接納結果」。
4.  不要只因見到新主入場便假設必然注資或炒高。
5.  新主取得上市地位後可能真正做業務，也可能有其他目的；資料不足時不要強行解讀。
6.  殼質素要看財務包袱，而不是只看上市地位。
7.  NAV 要拆開看資產、負債及現金，尤其要防止把帳面高估資產當成真實價值。
8.  老師提及部分「傳聞」及帳目敏感情況時，本身亦有保留語氣，不能把這些內容提煉成普遍事實。
9.  部分公司名稱、股票代號及人物名稱在逐字稿辨識不清，不以外部資料補正。
10. 本課主要講 GO；Non-GO
    只作分類預告，不應根據本附件自行補充其完整規則。

## 本課總結

《逐字稿-中細價股炒股課程Class 02B-葉子》主要建立兩套互相關聯的知識：

**第一套是「買殼／控制權轉移」；\
第二套是「GO 全面收購的結構與判斷」。**

買殼的核心是：

**舊主出售控制權 → 新主取得上市公司 → 新主可能再注入自己的資產或業務。**

老師強調，買殼只是一種取得上市平台的工具，本身不應直接被定義為好或壞。

研究 GO 時，核心流程是：

**確認控制權轉移\
→ 分強制／自願\
→ 分有條件／無條件\
→ 看觸發門檻\
→ 看要約價\
→ 看完成條件\
→ 看最終接納\
→ 看新舊貨源如何交收。**

強制性 GO 的課堂重點數字包括：

-   由 30% 以下升至 30% 或以上；
-   本身持有 30%--50% 時，12 個月內再增持約 2%。

而有條件 GO 的重要紀律是：

**提出收購不等於完成收購。**

必須等待最終條件是否達成。

在買殼選擇方面，本課再加入「殼質素」：

**上市地位本身有價值，但新主亦要承擔公司的舊問題。**

因此不能只找「爛公司」，而要分辨：

-   虧損是否可處理；
-   負債是否過重；
-   現金有多少；
-   NAV 是否可靠；
-   資產有沒有發水。

整體而言，本課不是把「GO」當成單一買入訊號，而是教學員把：

**控制權、人物、持股比例、收購條件、要約價、貨源交收及殼質素**

放在同一個框架內理解。
