## 核心觀念

### 1. Non-GO 的核心，是透過大量發行新股令控制權轉移

老師先用一個簡化股權例子說明：

- 公司原有 100 股；
- Public 持有 25 股，即 25%；
- 舊大股東持有 75 股，即 75%；
- 公司進行「1 供 4」，即發行 400 股新股；
- 假設所有原有股東都不跟供；
- 400 股新股全部由新主承接。

供股後總股數變成 500 股：

- Public：25 / 500 = 5%；
- 舊主：75 / 500 = 15%；
- 新主：400 / 500 = 80%。

老師藉此指出，雖然舊主沒有直接把原有股份出售給新主，但透過大量新股，新主已取得公司的主要控制權，舊主及公眾股東則被大幅攤薄。

這是本課理解 Non-GO 的最基本模型：

**大量新股 → 新主承接 → 舊股東被攤薄 → 控制權實質轉移。**

### 2. GO 與 Non-GO 的主要分別，在於控制權交收方式

老師把 GO 描述為較直接的控制權交收：

**舊主直接把大比例舊股交給新主 → 舊主退出／大幅退出 → 新主取得控制權 → 按相關規則進行 GO。**

Non-GO 則不是由舊主直接把整批舊股賣給新主，而是：

**上市公司發行大量新股 → 新主認購 → 新主取得高比例股權 → 舊主仍保留部分持股。**

因此兩者雖然都可以令公司「換主人」，但股權交收路徑不同。

### 3. Non-GO 的重要特徵，是舊主未必完全離場

老師反覆指出，Non-GO 與典型 GO 的一個重要差別，是舊主仍可能留在股權架構內。

例如上述模型中：

- 新主持有 80%；
- 舊主仍持有 15%。

因此不能只看到「新主已取得控制權」便當成舊主已完全離場。

分析時要同時看：

- 新主取得多少；
- 舊主剩下多少；
- 公眾股東被攤薄至多少；
- 舊主與新主是否同時留在公司內。

### 4. 清洗豁免是理解 Non-GO 的核心文件線索

老師指出，新主若因認購大量新股而取得很高比例股份，正常會碰到 GO 相關門檻；但在 Non-GO 結構中，可能同時申請「清洗豁免」。

課堂對清洗豁免的功能性解釋是：

**即使新主因新股認購取得很大比例股權，獲得清洗豁免後，可以不用按一般情況進行 GO。**

因此研究這類控制權轉移時，不能只搜尋「GO」，亦要留意：

- 大比例新股認購；
- 股權架構大幅改變；
- 清洗豁免；
- 新主與舊主供股／認購前後的持股比例。

### 5. 分析控制權轉移一定要自己重建「供前／供後」股權架構

本課最重視的實際能力之一，是不要只讀公告文字，而要把股數重新計算。

老師建議的思考方法是先假設公司原有一個簡單股數，例如 100 股，再計算：

**原有股數  
→ 新發行多少股  
→ 誰承接新股  
→ 完成後總股數  
→ Public 剩多少  
→ 舊主剩多少  
→ 新主持有多少  
→ 誰取得實際控制權。**

很多 Non-GO 的重點，只有在計完供前供後的比例後才會明顯。

### 6. 老師以「50% 加一股」解釋絕對控制權

課堂以簡化概念說明：

**持有超過 50%（老師表述為 50% 加一股），原則上已取得非常強的控制能力。**

因此研究大比例新股認購時，不能只問「新主買了多少股」，而要問：

**完成交易後，新主最終佔整間公司的百分比是多少？**

### 7. Non-GO 的吸引力在於「便宜、快、較能隱藏」

老師把採用 Non-GO 而不是正常 IPO／較公開的控制權交收方式的主要優點概括為三項：

1. **便宜**；
2. **快**；
3. **較能隱藏資料／意圖。**

老師指出，正常上市或其他正式程序涉及較高成本、較長時間及較多公開披露；Non-GO 透過大量新股及相關財技安排，可以在市場一般參與者未必容易理解的情況下完成控制權變化。

因此閱讀通告能力非常重要：不懂財技及股權計算的人，可能只看到「認購新股」，卻看不到背後其實已發生控制權交收。

### 8. 選股應大量使用「排除法」

老師在講解 Non-GO 時插入一個重要選股原則：

**排除法是有效而且較安全的選股方法。**

不是從全市場逐隻猜哪一隻會升，而是先把明顯不符合條件的股票篩走。

課堂提到可以根據：

- 市值；
- 供股／配股等財技；
- 價格過高或過低；
- 股票類型；
- 其他課程已建立的排除條件；

逐層縮小範圍。

老師的思路是：

**先知道甚麼不要 → 大量剔除 → 剩下少量值得研究的股票 → 再深入分析。**

### 9. 買殼／控制權轉移後，真正重要的是新主及後續資產注入

老師強調，GO 或 Non-GO 只是控制權交收方式，真正能令一隻原本的中細價股產生巨大變化的，是新主進場後：

- 新主本身是甚麼人物／班底；
- 是否有能力；
- 是否有資產；
- 是否會把新業務或資產注入上市公司；
- 公司是否因而由原本的細價股變成市場熱門概念。

課堂用多個歷史股票案例說明，有些股票在控制權轉移及資產注入後，市值及股價可以發生非常大的變化。

但老師亦明確提醒，不能一概而論。

### 10. 「現金公司」規則會限制單純大量注入現金的做法

課堂提及上市規則 14.82，老師以「現金資產公司／現金公司」作簡化解釋。

核心意思是：若上市公司大量發行新股，而新主只是把大量現金注入公司，公司可能因資產結構過度變成現金而碰到相關限制。

因此 Non-GO 並不是「想印多少新股便印多少」；實際設計要同時處理：

- 新股比例；
- 新主取得的控制權；
- 公司收到甚麼資產／現金；
- 上市規則限制；
- 公眾持股要求。

課堂對規則細節存在大量語音辨識失真，因此不把不確定內容提煉成更精確的監管公式。

### 11. 控制權轉移後仍要看公眾持股量

在前述 1 供 4 的極端例子中，新主持有 80%，Public 只剩 5%，顯然不能只停在這個理論數字。

老師在講解時亦提到要回到公眾持股要求。

因此股權計算至少有兩層：

**第一層：誰取得控制權？  
第二層：完成後的股權架構是否仍符合公眾持股要求？**

### 12. 白武士重組股是本課後半段的核心財技類型

老師把白武士重組股形容為財技股中非常核心的一類。

基本情境是：

- 上市公司已陷入嚴重問題；
- 可能停牌、債務沉重、業務困難或面對清盤；
- 原有股東／債權結構已難以維持；
- 新投資者以「白武士」身份進場；
- 透過債務、股權、供股／認購、重組等安排重新整理公司；
- 公司有機會恢復較清晰的股權架構並復牌。

老師認為這類股票的潛在變化可以非常大，但其複雜度亦高。

### 13. 白武士願意「執爛攤子」，是因為可能取得非常有利的成本及控制權

老師的核心邏輯不是「公司差所以值得買」，而是要問：

**白武士為甚麼願意接手？他用甚麼代價取得甚麼東西？**

在困難公司中：

- 舊股東可能已被大幅攤薄；
- 債權人需要重組；
- 白武士可以用較低成本取得大量新股或控制權；
- 完成重組後，股權結構可能變得非常集中及清晰。

因此研究白武士重組，重點是計算重組後誰真正控制公司，以及其取得控制權的代價。

### 14. 重組股的潛在回報與風險都非常極端

老師以多個歷史案例說明，部分成功重組的股票後來曾出現非常大的炒作幅度。

但這並不等於「白武士＝必升」。

真正要研究的是：

- 公司是否能完成重組；
- 是否能復牌；
- 新主取得多少股權；
- 舊債如何處理；
- 新主背景；
- 重組後是否有新故事／新資產；
- 貨源是否高度集中。

### 15. 市場「熟悉度／股票號碼的宣傳價值」可能影響派貨能力

課堂後段提到，有些股票號碼本身因市場長期熟悉而具有一定「宣傳價值」。

老師的意思是：

- 市場認識度高；
- 潛在參與者／客源較多；
- 當股票被重新包裝或炒作時，較容易吸引市場注意；
- 對後續散貨可能有幫助。

這屬老師對市場行為的觀察，不應延伸為「知名號碼必然較好」的固定規則。

## 判斷條件與邏輯

### 一、判斷是否屬 Non-GO 控制權轉移

依次檢查：

1. 公司是否大量發行新股；
2. 新股比例相對原股本是否非常大；
3. 新股由誰認購／包銷；
4. 新主完成後持股比例；
5. 舊主完成後是否仍持股；
6. Public 被攤薄至多少；
7. 是否出現清洗豁免；
8. 完成後是否實質改變控制權。

不能只因見到「認購新股」便判定為 Non-GO；核心是**新股發行是否實質造成控制權轉移**。

### 二、計算股權時先用絕對股數，再轉百分比

老師的示範方法：

1. 假設原有 100 股；
2. 把各方原有股數寫出；
3. 計算新增股數；
4. 確定誰承接；
5. 得出完成後總股數；
6. 各方股數 ÷ 新總股數；
7. 比較供前與供後控制權。

這比只看公告中的百分比更容易理解攤薄效果。

### 三、看到清洗豁免，要回頭問「為何本來會觸發 GO」

分析清洗豁免不能只記住「不用 GO」。

應反向研究：

- 新主因甚麼交易取得大量股份；
- 如果沒有豁免，本來為甚麼會觸發 GO；
- 豁免後新主實際取得多少控制權；
- 舊主是否仍在；
- 整個交易是否構成變相賣殼／控制權轉移。

### 四、GO／Non-GO 後不能立即以「新主入場」推導股價結果

要再研究：

- 新主背景；
- 新主過往紀錄；
- 新主取得上市平台的目的；
- 是否有資產／業務可注入；
- 是否真正有後續公司行動；
- 股權及貨源是否有利後續操作。

### 五、白武士重組先看「生存問題」，再看炒作問題

白武士案例首先要處理：

**公司能否被救活／完成重組／恢復交易。**

之後才研究：

- 新主成本；
- 控制權；
- 股權集中度；
- 資產注入；
- 後續炒作空間。

不能把「有白武士」直接等同「重組已成功」。

### 六、用排除法縮小研究範圍

老師的選股思路可以整理為：

**全市場  
→ 排除不研究的大型／不合類型股票  
→ 排除不符合市值條件  
→ 排除財技結構不理想者  
→ 排除價格／位置不合者  
→ 剩下較少標的  
→ 再逐隻深入看人物、財技及股權。**

## 老師重點

- Non-GO 不是沒有控制權轉移，而是控制權轉移的方式不同。
- 大量發行新股可以極大幅度攤薄原股東。
- 研究供股／認購必須重建完成前後股權架構。
- 新主取得多少「百分比」比單看認購多少股更重要。
- 舊主在 Non-GO 中可以繼續留在公司。
- 清洗豁免是辨認部分 Non-GO 結構的重要線索。
- GO 與 Non-GO 都只是交收工具，後續價值仍取決於新主及其行動。
- Non-GO 的核心優勢，老師概括為便宜、快、較能隱藏。
- 不懂通告及財技的人，可能看不到控制權已在股權結構中改變。
- 選股應大量使用排除法，而不是在全市場盲目找「必升股」。
- 買殼後若有強勢人物及優質資產注入，股票性質可以完全改變。
- 不能把所有 GO／Non-GO 股票一概而論。
- 監管規則會限制財技設計，不能假設公司可以無限印股。
- 白武士重組是高複雜度、高變化幅度的財技類型。
- 白武士案例要研究的是新主如何用重組取得控制權，以及公司如何由困境重新建立股權結構。
- 課堂案例中的巨大升幅是歷史案例，不是普遍保證。

## 操作流程

### Step 1：先找控制權事件

從公告中找：

- 大比例認購新股；
- 供股；
- 新投資者；
- GO；
- 清洗豁免；
- 白武士／重組；
- 重大股權變動。

### Step 2：畫出交易前股權架構

記錄：

- Public；
- 舊大股東；
- 其他主要股東；
- 各自股數及百分比。

### Step 3：計算新股數量

把供股／認購比例轉成實際股數。

必要時像老師示範一樣，把原股本簡化成 100 股重新計算。

### Step 4：確認新股最終落在誰手上

區分：

- 舊主跟供；
- Public 跟供；
- 新主認購；
- 包銷商／其他人士承接。

### Step 5：重建完成後股權架構

計算：

**完成後總股數 → Public % → 舊主 % → 新主 % → 其他主要股東 %。**

### Step 6：判斷控制權是否實質轉移

比較供前／供後：

- 誰由少數變成大股東；
- 誰跌至次要位置；
- 是否有人超過老師所說的絕對控制水平；
- 舊主是否仍然存在。

### Step 7：檢查是否有清洗豁免

如有：

- 找出申請豁免的原因；
- 理解本來可能觸發的 GO；
- 不要因「沒有 GO」便忽略實質控制權變化。

### Step 8：檢查公眾持股及其他限制

不能只完成控制權計算。

還要看交易完成後是否需要：

- 調整公眾持股；
- 處理現金公司等規則問題；
- 進一步配售／安排股份。

### Step 9：研究新主及後續動作

控制權交收後追蹤：

- 董事變動；
- 資產注入；
- 新業務；
- 再融資；
- 供股／配股；
- 公司名稱／定位改變；
- 其他重大交易。

### Step 10：如屬困境公司，建立白武士重組時間線

依序整理：

**停牌／財困  
→ 債務或清盤問題  
→ 白武士出現  
→ 重組方案  
→ 新股／供股／債務安排  
→ 股權重新分配  
→ 新主取得控制權  
→ 復牌  
→ 後續資產／業務及炒作。**

### Step 11：最後才評估是否值得進一步研究

先用排除法剔除不合條件者，再把時間集中在：

- 控制權結構清晰；
- 新主值得研究；
- 重組／財技進度可追蹤；
- 股權變化明確；

的標的。

## 重要案例

### 案例一：1 供 4 的 Non-GO 股權模型

原股本 100 股：

- Public 25；
- 舊主 75。

發行 400 股新股，全部由新主承接。

完成後：

- Public：5%；
- 舊主：15%；
- 新主：80%。

案例用途：

**證明不用舊主直接賣股，也可以透過大量新股令控制權完全改變。**

### 案例二：939 的清洗豁免示例

老師展示一宗股票代號 939 的歷史通告，指出通告同時出現：

- 建議認購新股份；
- 大比例新股由新投資者取得；
- 清洗豁免。

案例用途不是要求記住股票，而是學會看到：

**新股認購 + 清洗豁免 → 應立即重建供前供後股權，檢查是否存在 Non-GO 控制權轉移。**

### 案例三：708／恆大健康相關歷史案例

老師以 708 的歷史控制權事件說明：

- 股票可由 GO／買殼開始；
- 新主及班底進場後；
- 再配合後續資產／概念；
- 原本股票的市場定位可以完全改變。

課堂提及其歷史上曾出現極大升幅，目的在說明控制權轉移後的潛在變化可以非常大，而不是建立「GO 股票必升」規則。

### 案例四：金彩控股相關 Non-GO／清洗豁免案例

老師展示一宗大量發行新股的案例，提及：

- 大量股權易手；
- 舊主未完全離場；
- 新主透過新股取得大比例股份；
- 同時申請清洗豁免。

逐字稿對股票名稱、比例及部分交易細節有辨識失真，因此只保留其教學用途：

**觀察新股比例、清洗豁免及完成後股權，而不是只看公告標題。**

### 案例五：1701 及 WhatsApp 群組風險

老師提到部分市場群組可能先讓參與者在前幾次交易賺錢，建立信任及貪念，再令參與者在後續股票承受重大損失。

老師把核心心理問題指向「貪」。

案例用途：

**過往曾跟某個消息來源賺錢，不代表下一次仍可信；先前盈利甚至可能令人降低戒心。**

### 案例六：白武士重組案例群

課堂後半段用多個歷史困境公司／白武士案例說明：

- 公司可以先停牌或陷入財困；
- 白武士以低成本參與重組；
- 大量新股及債務安排令原股權被重寫；
- 白武士可取得非常高比例控制權；
- 重組完成後公司復牌；
- 部分個案其後出現巨大炒作幅度。

由於逐字稿中多個公司名稱、人物名稱及精確數字辨識不穩定，不自行以外部資料補正。

## 例外與容易誤判情況

### 1. 新主持股大幅增加，不等於一定屬典型 GO

要看股份是：

- 向舊主買入；
- 還是由公司發行新股取得。

### 2. 沒有 GO，不等於沒有控制權轉移

若有大比例新股及清洗豁免，控制權仍可能已實質改變。

### 3. 有清洗豁免，不等於股票一定值得投資

清洗豁免只解釋交易／控制權結構，不能直接推導股價結果。

### 4. 新主很有名，不等於後續一定成功

仍要看實際注資、業務及公司行動。

### 5. GO 股票曾出現百倍案例，不等於 GO 是百倍股公式

課堂歷史案例只說明可能性。

### 6. 舊主仍持股，不等於舊主仍掌握控制權

必須看完成後的相對持股比例。

### 7. 大量新股不一定全部代表「賣殼」

要看交易目的、承接者、完成後控制權及相關公告。

### 8. 白武士出現，不等於重組必然完成

仍存在：

- 重組失敗；
- 條件未達成；
- 復牌不成功；
- 股權／債務安排改變；

等不確定性。

### 9. 公司已跌至極低價，不等於白武士介入後沒有再攤薄風險

重組本身可能需要大量新股、供股或其他安排。

### 10. 股票號碼有市場認知度，只是可能增加關注／散貨條件

不能把「知名號碼」單獨變成選股規則。

### 11. 課堂監管數字不可脫離當時語境使用

逐字稿提及 GO 門檻、50%、公眾持股、14.82 等規則時，是老師當時課堂的講解。

本摘要只保留其在本課分析框架中的作用，不自行更新或延伸成現行監管規則。

## 注意事項

1. 本課大量涉及 GO、Non-GO、清洗豁免、現金公司、供股、認購及白武士重組，分析時必須把不同概念分開。
2. 最重要的實務動作是「計股權」，不要只讀公告文字。
3. 大比例發新股的效果必須用完成後總股本重新計算，不能沿用交易前百分比。
4. 控制權分析要同時看新主、舊主及 Public，而不是只看最大股東。
5. 清洗豁免應視為進一步研究的訊號，不是利好結論。
6. 新主取得上市公司後是否有後續資產／業務，決定故事能否延續。
7. 白武士重組的回報案例很大，但失敗風險及結構複雜度亦高。

10. 課堂部分股票代號、公司名、人名及精確比例存在嚴重語音辨識問題，不能可靠確認者均不應自行補全。

## 本課總結

《逐字稿-中細價股炒股課程Class 03-葉子》的核心，是把上一層的「買殼／控制權轉移」概念進一步落到 **Non-GO、清洗豁免、股權計算及白武士重組**。

最重要的第一條知識是：

**控制權轉移不一定要靠舊主直接賣股。**

公司可以大量發行新股，由新主承接，令原有股東被攤薄，新主在完成後取得主要甚至絕對控制權。

因此分析 Non-GO 時，核心不是公告名稱，而是：

**原股本  
→ 新股比例  
→ 誰承接  
→ 完成後總股本  
→ 新主 %  
→ 舊主 %  
→ Public %  
→ 是否清洗豁免  
→ 控制權是否實質轉移。**

第二條核心，是：

**GO／Non-GO 只是取得上市平台及控制權的方式，真正影響後續故事的是「新主是誰、取得甚麼、之後做甚麼」。**

所以控制權交收後，仍要追蹤：

**人物 → 股權 → 董事 → 資產 → 業務 → 再融資 → 後續財技。**

第三條核心，是白武士重組。

當上市公司陷入嚴重困境時，白武士可能透過重組、債務安排及大量新股，以較低成本取得控制權；若重組成功，公司可以由停牌／財困重新建立股權結構並復牌。這類個案可能產生巨大變化，但同時存在重組失敗、復牌失敗及高度攤薄等風險。

整套課堂方法可以濃縮為：

**先用排除法縮小股票範圍  
→ 找控制權事件  
→ 自己計供前／供後股權  
→ 分辨 GO 或 Non-GO  
→ 找清洗豁免及相關限制  
→ 研究新主與舊主是否仍在  
→ 追蹤後續資產／業務  
→ 困境公司再研究白武士重組  
→ 不把歷史大升幅案例當成必然結果。**
