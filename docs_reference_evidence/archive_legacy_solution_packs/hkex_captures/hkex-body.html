              You can search for CCASS shareholding information in the past 12 months. Shareholding information displayed represents the shareholdings of CCASS Participants as at the end of the specified date (except for Stock Connect Northbound Shareholding). If the specified shareholding date is a Sunday or a Hong Kong public holiday, shareholding information on the preceding day which is not a Sunday or Hong Kong public holiday will be displayed.

              To start searching, please select a Shareholding Date and enter a Stock Code or Name. You may also enter a CCASS Participant ID or CCASS Participant Name if you only want to search for the shareholdings of a particular CCASS Participant on the specified security and date.
